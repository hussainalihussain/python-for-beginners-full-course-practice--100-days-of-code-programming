## 🚀 How to Use This Repository

1. **Start with fundamentals** - Begin with Day-1 through Day-35 to master Python basics
2. **Practice data structures** - Days 22-34 cover essential data structures
3. **Learn OOP** - Progress through Days 56-81 for object-oriented programming
4. **Explore advanced topics** - Days 84-98 cover advanced and specialized topics
5. **Run the scripts** - Execute Python files to see concepts in action:
   ```bash
   python "Day-10/10-user-input.py"
   python "Day-22-Lists/22-lists.py"
   python "Day-56-OOP/oop.py"
   ```
