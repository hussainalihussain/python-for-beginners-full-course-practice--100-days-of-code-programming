# Practice All The Course

This folder is a revision pack built from your main [README.md](../README.md) and the Python patterns already present in this repository.

The goal is not to give you ready-made answers. Each file contains commented exercises and starter stubs so you can practice from memory and quickly spot weak areas.

## How To Use It

1. Start from `exercise-01-fundamentals.py`.
2. Solve directly inside the file by replacing `pass`.
3. Try not to open the original day folders unless you get stuck.
4. After solving, run your code and compare it with your old lesson files.

## Suggested Order

- `exercise-01-fundamentals.py` - print, variables, input, type casting, beginner challenges
- `exercise-02-conditions-and-loops.py` - if/else, match-case, for, while, break, continue, for-else
- `exercise-03-functions-and-recursion.py` - functions, default args, `*args`, `**kwargs`, docstrings, recursion
- `exercise-04-strings-and-formatting.py` - strings, slicing, methods, f-strings, secret-code style logic
- `exercise-05-data-structures.py` - lists, tuples, sets, dictionaries
- `exercise-06-exceptions-modules-and-os.py` - try/except, `finally`, `raise`, imports, `__main__`, `os`
- `exercise-07-file-handling.py` - read, write, append, `readlines`, `seek`, `tell`, `truncate`
- `exercise-08-functional-and-python-features.py` - lambda, map/filter/reduce, enumerate, walrus, generators, decorators, caching
- `exercise-09-oop-basics.py` - classes, methods, class variables, static methods, class methods, properties
- `exercise-10-oop-advanced.py` - inheritance, overriding, `super`, mangling, dunder methods, operator overloading
- `exercise-11-project-style-practice.py` - course-style mini projects
- `exercise-12-advanced-topics.py` - regex, requests, argparse, asyncio, threading, multiprocessing

## Notes

- Some exercises combine multiple course days into one revision task.
- A few prompts ask you to create extra helper files. That is intentional because your course also covered imports, file handling, and CLI work.
- These files are only prompts and scaffolding. They are meant to stay incomplete until you solve them.
