## 🔧 Installation

### 1. Clone the main repository

```bash
git clone https://github.com/hussainalihussain/python-for-beginners-full-course-practice--100-days-of-code-programming
cd python-for-beginners-full-course-practice--100-days-of-code-programming
```

---

### 2. Navigate to this exercise

```bash
cd Day-90-exercise-10
```

---

### 3. Install dependencies

```bash
pip install requests python-dotenv
```

---

### 4. Create `.env` file from example

```bash
cp .env.example .env
```

---

### 5. Add your API key

Open `.env` and replace:

```env
NEWS_API_KEY=your_api_key_here
```

👉 Get your API key from: [https://newsapi.org/](https://newsapi.org/)

---

## ▶️ How to Run

```bash
python exercise-10-news-app.py
```
